### 2. 从"建议"到"规则 + 决策树"

**优化前**:
```
- 预置"运行态告警"典型故障模式：增加一条典型故障逻辑规则——当检测到"设备处于运行中（OperatingStatus正常）+ 总故障状态为False + 仅有单点告警"时，优先将搜索路径收敛于"定值/阈值配置不合理"、"采样回路偏差"或"信号误发"，减少对真实硬件故障的无效发散。
```

**优化后**:
```
#### 模式 1: 运行态告警
**识别**: 设备正常运行 + 总故障 false + 单点告警  
**推理路径**: 定值配置 → 采样偏差 → 信号误发  
**禁止**: 硬件故障假设  
**案例**: TEST-1774925781037
```

**优势**:
- 结构化表达，易于理解
- 明确"识别特征"、"推理路径"、"禁止操作"
- 关联具体案例，便于验证

```

**案例**: 8352（母线电压差114V，956.4V vs 842.2V）

**优势**:
