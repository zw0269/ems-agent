## 🎓 典型案例深度分析

### 案例 1: 母线电压不自洽（8352）

**问题**: 
- `UpVol + DownVol = 956.4V`
- `TotalDirectVol = 842.2V`
- 偏差 114V（13.5%）

**优化前推理路径**:
1. 查询 PCS 电压 → 发现不匹配
2. 查询 BMS 电压 → 对比
3. 查询电表电压 → 对比
4. 查询历史趋势 → 分析
5. 查询保护定值 → 判断
6. 输出结论: 电压不匹配（6 次迭代）

**优化后推理路径**:
1. **R1.2 自动触发**: 母线电压不自洽 → 直接判定为采样配置错误
2. 输出结论: 采样系数配置/寄存器映射/通讯解析错误（1 次迭代）

**改进效果**: 迭代次数 -83%，准确率 +100%

---

### 案例 2: VF 离网孤岛带载误判（8669）

**问题**:
- `pcsVfOffGridStatus = true`
- `pcsOperatingStatus = 运行`
- `batteryPower = 21.9kW`（有功率输出）
- `pcsOverallFaultStatus = false`

**优化前推理路径**:
1. 检测到 VF 离网 → 判定为故障
2. 查询设备状态 → 发现运行中
3. 查询功率 → 发现有输出
4. 逻辑矛盾 → 反复查询
5. 输出结论: 保护失效导致未停机（错误结论，6 次迭代）

**优化后推理路径**:
1. **R4 VF 状态三分类**: 运行 + 有功率 >5kW → 孤岛带载模式
2. 输出结论: VF 正常孤岛运行，确认保电策略（1 次迭代）

**改进效果**: 迭代次数 -83%，避免误判

---

### 案例 3: 高频振荡（8659）

**问题**:
- 14 次/26 秒并离网循环
- 频率 49.8Hz（接近下限 49.5Hz）

**优化前推理路径**:
1. 查询频率 → 发现接近下限
2. 查询电网状态 → 正常
3. 查询保护定值 → 未获取
4. 查询历史趋势 → 发现高频反复
5. 输出结论: 电网扰动（错误结论，6 次迭代）

**优化后推理路径**:
1. **R3 振荡/抖动模式识别**: 14 次/26 秒 → 直接跳转到振荡排查分支
2. 输出结论: 定值死区过小/采样干扰/接触器抖动（2 次迭代）

**改进效果**: 迭代次数 -67%，准确率 +100%
